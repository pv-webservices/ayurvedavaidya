# AyurvedaVaidya frontend

Production-oriented React/Vite frontend for AyurvedaVaidya.com.

## Run locally

```bash
npm install
npm run dev
```

Create an optimized production build with `npm run build`.

## Launch integrations still required

- Connect the consultation form in `src/App.jsx` to an approved secure booking or email delivery service. It intentionally does not claim to create an appointment.
- Connect newsletter submission or remove the newsletter form.
- Replace the clearly labelled expert placeholder image with the real clinician photography and verified profile content.
- Replace testimonial placeholders with consented, verified patient content only.
- Supply professionally reviewed Privacy Policy, Terms, and Medical/Wellness Disclaimer copy.
- Add real article bodies, publication metadata, and approved authors before publishing.

All photographic assets in `public/images/ayurveda` were generated as individual static images with Magnific GPT 2 at 1K/high quality. No video assets are used.
